## 1. 已确认的研究事实与术语（来自作者本次说明与底稿；不得更改）

- 两个实验，独立样本。Exp 1：理解（是否判断）；Exp 2：开放式视频描述产出。
- 被试：4 岁、5 岁儿童各 32 名（每个实验）；1010 稿另有成人各 40 名（作者本次 RQ 文本未提成人 → 见待决事项 D2）。
- 材料：10 对 V1–宾语表达；每对共享宾语和目标结果（V2），每对一个“预期结果关联较强”、一个“较弱”的成员（两组各 10 个）；每个动作拍 full-result / zero-result 两版，共 40 个关键视频。
- 术语：target result (V2) = 配对 RVC 中 V2 所表达的结果，“target”不表示意图或预期；full-result event = 目标结果可见地达成；zero-result event = 动作发生但目标结果未达成。
- 成人评定：N1 = result likelihood（做了该 V1–宾语动作后目标结果出现的可能性，0–100）；N3 = action typicality（该动作作为达成该结果的手段有多典型，1–7）。评定对象是句子中的 V1–宾语表达，不是视频。
- 评定事实（1010 稿 / 0924 稿）：N1 在 10 对中方向全部符合预期（P8 不可靠）；N3 8 对同向，P7（qiā vs. jiào）反向，P8 不可靠；两种配对差异相关 r = .79。
- RQ（作者本次给定，以此为准）：
  - Exp 1 RQ1：儿童对 V1 与 RVC 描述的接受度在 full- vs zero-result 事件间是否不同。
  - Exp 1 RQ2：在宾语和目标结果匹配的配对内，V1 描述接受度是否随 N1、N3 连续评分变化；先分别检验，再看任一指标在控制另一指标后是否解释额外变异；不预设儿童判断只反映可能性。
  - Exp 2：结果实现是否影响儿童是否使用 RVC；在不提及其他结果的纯单语素回答中，区分仅动作 / 仅目标结果 / 两者分开表达；目标结果的肯定或否定另行编码。
- N1/N3 不作为产出实验的主要预测变量（0924 稿理由：评定针对指定表达，产出任务不提供表达，视频未按 N1/N3 评定）。

## 2. 论文核心论证（修订后 Introduction 要承担的论证链）

1. RVC 用 V2 显性表达结果；单语素 V1 只表达动作，结果为可取消的推理而非蕴含（Tai, 1984; Talmy, 1991; Liu et al., 2026）。
2. 习得研究：儿童早期产出 RVC、理解中对结果敏感；但前人研究发现儿童在 zero-result 事件中比成人更常拒绝 V1 描述——这是出发点，不是研究对象。
3. 成人对 V1 的结果解读本身也因 V1 而异（Chen, 2018），而现有对 V1 的分类以动词为单位、标准不一（Talmy / Kou & Hohenstein / Chen / Martin et al.），旧稿的 Strong/Weak 标签也不清楚 → 因此不能只对比 RVC 与 V1，还需比较不同 V1，且需要明确刻画“不同”在哪里。
4. 用两个维度刻画 V1 与目标结果的关系：result likelihood（从动作看结果）与 action typicality（从结果看动作）；两者相关但不等同（Barsalou, 1985; Kim & Murphy, 2011），且对儿童判断有不同的解释路径（推理 vs. 典型性，Ma et al., 2021）。
5. 竞争解释及其预测 → RQ1/RQ2 的设计；产出实验补足“儿童自己选择表达什么”。
